# Webhook Panel
Webhook Panel — это кастомная панель для Home Assistant, которая позволяет просматривать и запускать webhook-автоматизации из Home Assistant в виде кнопок.

Интерфейс без авторизации доступен по адресу ```/local/webhook_panel/index.html```

Важно! Пользователь сам создаёт автоматизации с webhook в Home Assistant. Панель только отображает их в виде кнопок.
